# Коммерческое предложение: Lumo × Impact Admission

**Дата:** июнь 2026  
**От:** Lumo — AI-платформа поиска возможностей для школьников и студентов  
**Кому:** Impact Admission  
**Контакт бота:** [t.me/LumoAI1bot](https://t.me/LumoAI1bot)

---

## 1. Кратко

**Lumo** — Telegram-бот с ИИ, который 24/7 мониторит каналы с грантами, стипендиями, олимпиадами, летними школами, конкурсами и стажировками и присылает ученику **только то, что подходит под его профиль**.

**Impact Admission** помогает школьникам выигрывать возможности и поступать зарубеж — стратегия, сопровождение, эссе, выбор программ.

**Предложение:** подключить Lumo как инструмент для клиентов Impact, чтобы ученики не пропускали дедлайны, а консультанты меньше тратили время на ручной поиск в Telegram и Google.

> Impact занимается **стратегией поступления**.  
> Lumo занимается **поиском возможностей и дедлайнов**.

---

## 2. Проблема

Для компании вроде Impact Admission типичны такие боли:

| Проблема | Последствие |
|----------|-------------|
| Сотни Telegram-каналов и сайтов с программами | Консультанты тратят часы на ручной поиск |
| Дедлайны разбросаны по постам и языкам | Ученики пропускают гранты, олимпиады, летние школы |
| У каждого ученика свой профиль | Общая рассылка «топ-10 программ» не работает |
| Конкуренты добавляют «технологичность» | Сложнее выделиться только консультациями |

Пропущенная летняя школа или олимпиада — это слабее портфолио при поступлении. Impact не может физически следить за всеми каналами для каждого клиента.

---

## 3. Решение — Lumo

### Что делает Lumo

1. **Мониторинг** — автоматически отслеживает Telegram-каналы с возможностями (гранты, стипендии, хакатоны, олимпиады, летние школы, конкурсы, стажировки).
2. **ИИ-классификация** — извлекает из постов название, тип, дедлайн, требования и ссылку на заявку; отфильтровывает рекламу и спам.
3. **Персонализация** — ученик один раз описывает себя (`/set_interest`), дальше бот присылает только релевантное.
4. **Доставка в Telegram** — подборки приходят туда, где ученик уже сидит каждый день.

### Как пользоваться (3 шага для ученика)

| Шаг | Действие |
|-----|----------|
| 1 | Открыть бота по ссылке Impact |
| 2 | Написать о себе: возраст, интересы, цели (США, медицина, IT и т.д.) |
| 3 | Получать персональные подборки с дедлайнами |

### Что Lumo **не** делает

- Не пишет мотивационные письма и эссе  
- Не выбирает вузы и не строит стратегию поступления  
- Не готовит к SAT / IELTS  
- Не заменяет консультанта Impact — **дополняет** его работу

## 5. Услуги для Impact Admission

Предлагаем три формата. Можно начать с одного и масштабировать.

### Услуга A — «AI-поиск для ваших клиентов» *(рекомендуем для старта)*

**Для кого:** ученики Impact Admission  
**Суть:** Impact даёт каждому клиенту доступ к Lumo как часть пакета сопровождения.

**Что получает Impact:**
- Партнёрская ссылка с атрибуцией (`t.me/LumoAI1bot?start=impact_...`)
- Видимость: сколько клиентов подключились и пользуются ботом
- Возможность выдавать доступ по тарифу (пробный / полный / безлимитный)
- Усиление value proposition: «Мы даём не только консультанта, но и AI, который ищет возможности 24/7»

**Что получает ученик:**
- Персональный AI-поиск грантов, олимпиад, летних школ, конкурсов
- Уведомления о подходящих программах в Telegram
- Меньше риска пропустить дедлайн

**Модель оплаты:** Impact платит Lumo за пакет мест (B2B) или за каждого активного ученика в месяц.

---

### Услуга B — «Помощник для консультантов»

**Для кого:** команда Impact (консультанты, не ученики)  
**Суть:** консультант вводит профиль ученика → ИИ выдаёт shortlist программ за секунды вместо часов ручного поиска.

**Что получает Impact:**
- Экономия времени команды на каждом клиенте
- Единый инструмент вместо хаотичного поиска в каналах
- Возможность быстро обновлять рекомендации при смене стратегии ученика

**Модель оплаты:** ежемесячная корпоративная подписка (SaaS) по числу консультантов или клиентов в базе.

*Срок запуска: обсуждается после пилота Услуги A.*

---

### Услуга C — «Брендированный бот Impact»

**Для кого:** ученики Impact  
**Суть:** отдельный или co-branded бот с логотипом и названием Impact (например, «Impact Opportunities»).

**Что получает Impact:**
- Собственный tech-продукт в глазах клиентов и родителей
- Кастомные тексты, welcome-сообщения, фокус на международные программы (US/UK/EU)
- Отдельные каналы мониторинга под admissions (DAAD, Fulbright, summer schools, olympiads)

**Модель оплаты:** setup fee + ежемесячная лицензия.

*Срок запуска: 4–8 недель после согласования ТЗ.*

## 9. Техническая схема (Пакет 2)

```
Telegram-каналы
      ↓
Lumo бот (мониторинг + ИИ-классификация)
      ↓
База конкурсов (автообновление)
      ↓
Partner API  →  GET /catalog/opportunities
      ↓
Платформа Impact (их sync раз в N часов)
      ↓
Ученики видят актуальные конкурсы
```

**Lumo не встраивается в их код** — отдаёт готовый JSON по API. Impact один раз настраивает автозагрузку на своей стороне.

### API (уже работает)

| Endpoint | Назначение |
|----------|------------|
| `GET /api/partner/v1/catalog/opportunities` | Список конкурсов (title, type, deadline, description, url) |
| `GET /api/partner/v1/health` | Проверка доступности |
| `Authorization: Bearer <API_KEY>` | Доступ только для Impact |

Пагинация: `?limit=200&offset=0` — Impact забирает порциями, пока `hasMore: true`.

### Техническая готовность

- **Partner API** — работает в production  
- **Каталог** — пополняется ботом автоматически  
- **Deep links + подписки** — для Пакета 1  
- **Разработка с нашей стороны для Пакета 2** — выдача API-ключа и краткая инструкция для их разработчика  

Для пилота (Пакет 1) достаточно партнёрской ссылки. Для Пакета 2 — API-ключ + 1 страница документации.
