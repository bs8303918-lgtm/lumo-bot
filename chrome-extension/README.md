# Lumo Chrome Extension (MVP)

Расширение для Chrome, которое быстро показывает новые конкурсы, гранты,
стипендии и хакатоны из каталога Lumo и подсвечивает бейджем на иконке,
когда появилось что-то новое. Дизайн — тёмная тема в стиле Telegram Mini
App (тот же каталог, что в `telegram-site/frontend`).

Никаких изменений на бэкенде не требуется — расширение ходит напрямую в
уже существующий продакшен API (`/api/auth/*`, `/api/lumo/opportunities`) с
тем же email/паролем, что и на сайте Lumo-site.

## Возможности MVP

- Вход/регистрация по email и паролю (тот же аккаунт, что на сайте).
- Лента каталога: заголовок, тип, дедлайн (с подсветкой срочности),
  источник, бейдж «NEW» для свежих записей — клик открывает ссылку на
  подачу/пост в новой вкладке.
- Поиск и фильтры по типу (гранты, стипендии, хакатоны, стажировки,
  конкурсы, олимпиады и т.д.).
- Кнопка «★» — добавить конкурс в личный трекер («Отслеживаю»), со
  статусами «Хочу подать» / «Подано» (хранится локально в
  `chrome.storage.local`, как и избранное в текущих Mini App).
- Фоновая проверка каталога каждые 30 минут (`chrome.alarms`) +
  системное уведомление и бейдж-счётчик на иконке расширения, когда
  появляются новые записи, которые пользователь ещё не видел.

## Как запустить локально

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `chrome-extension/`.
3. Открыть попап расширения, войти (или зарегистрироваться) тем же
   email/паролем, что и на `Lumo-site`.

## Конфигурация

`src/config.js` — единственное место, где задан адрес API
(`API_BASE`, сейчас продакшен Railway) и список типов для фильтров.

## Известные ограничения MVP

- Трекер («Отслеживаю») хранится только локально в расширении — это
  MVP-аналог локального избранного в Mini App, отдельного бэкенда для
  него пока нет (как и на сайте).
- Иконки — программно сгенерированный плейсхолдер, стоит заменить на
  финальный логотип перед публикацией в Chrome Web Store.
- Публикация в Chrome Web Store потребует отдельного review-процесса
  Google и, вероятно, доработки privacy policy (описание использования
  `storage`/`notifications`).
